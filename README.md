# Омода — подготовка к ММТ

Нативное Android-приложение на Kotlin и Jetpack Compose. Интерфейс на таджикском языке, без переключения языка. Работает без сети, регистрации и сервера.

## Открыть и запустить

Откройте эту папку в Android Studio, дождитесь Gradle Sync и нажмите Run. Нужны JDK 17 или 21, Android SDK 35. Минимальная версия телефона — Android 8.0 (API 26).

В Android Studio проверьте Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK: выберите JDK 21 или 17. На этом компьютере проверено с `C:\Users\ASUS\.jdks\jbr-21.0.11`.

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

Путь к SDK Android Studio задаст в локальном `local.properties`, либо используйте `ANDROID_HOME`. Не добавляйте этот машинный путь в Git. Для запуска Gradle используйте совместимый JDK: установленный JDK 25 с Gradle 8.13 несовместим.

## Что реализовано

- Доступны все пять кластеров.
- Кластер 1: Забони тоҷикӣ, Математика, Химия, Физика (1423 вопроса).
- Кластер 2: Забони тоҷикӣ, Математика, География, Забони англисӣ (790 вопросов).
- Кластер 3: Забони тоҷикӣ, Таърих, Адабиёти тоҷик, Забони англисӣ (1182 вопроса).
- Кластер 4: Забони тоҷикӣ, Таърих, Ҳуқуқ, Забони англисӣ (1284 вопроса).
- Кластер 5: Забони тоҷикӣ, Биология, Химия, Физика (1695 вопросов).
- Повторяющиеся предметы используют одни и те же банки и ключи: таджикский — во всех кластерах, математика — в 1/2, химия и физика — в 1/5, история — в 3/4, английский — в 2/3/4. Копии вопросов не создаются.
- В каждой попытке 25 случайных уникальных вопросов. Новая попытка получает новую случайную выборку; пересечения между разными попытками допустимы.
- Ответ фиксируется сразу и не меняется. Правильный вариант зелёный; ошибочно выбранный красный. Подписи и значки дублируют цвет.
- Следующий вопрос доступен после ответа. После 25-го — количество правильных/ошибочных ответов и процент.
- Повторная попытка и возврат к выбору предмета.
- ViewModel и SavedStateHandle сохраняют выбранный кластер, порядок вопросов, позицию и ответы при повороте экрана и восстановлении процесса системой. Это не постоянная история попыток: после намеренного выхода из теста попытка прекращается.
- Формулы и рисунки сохраняются визуальными фрагментами PDF; для вопроса доступно увеличение. Для научных предметов сохраняется исходная математическая/химическая типографика. Рисунок, стоявший сбоку от ответов, переносится целиком под условие.
- Водяной знак удаляется из временного представления PDF до рендеринга изображений. Оригиналы PDF не меняются.

Итого: 3491 уникальный вопрос. Общее количество учитывает каждый банк один раз. Все девять прежних банков и их изображения сохранены без изменений относительно APK 0.3. Литература добавлена из новой папки: все 312 вопросов с одним ответом, без пропусков; стихотворные строки и оформление вариантов сохранены визуальными фрагментами PDF. Для предметов кластера 2 сохраняется начальная выборка, указанная в таблице; остальные предметы включают весь раздел с одним правильным ответом.

Это учебная тренировка, а не полная модель официального экзамена и его баллов. Предварительное название «Омода» можно заменить.

## Как добавлять вопросы

Банки в `app/src/main/assets/{tajik,math,geography,english,biology,chemistry,physics,history,law,literature}.json`, изображения в `assets/questions/`. Каждый вопрос содержит:

```json
{
  "id": "tajik-201",
  "number": 201,
  "page": 30,
  "source": "source.pdf",
  "prompt": { "text": "Матни савол", "image": "", "width": 1, "height": 1, "visual": false },
  "options": [
    { "text": "Варианти A", "image": "", "width": 1, "height": 1, "visual": false },
    { "text": "Варианти B", "image": "", "width": 1, "height": 1, "visual": false },
    { "text": "Варианти C", "image": "", "width": 1, "height": 1, "visual": false },
    { "text": "Варианти D", "image": "", "width": 1, "height": 1, "visual": false }
  ],
  "correct": 0
}
```

`correct`: индекс 0=A, 1=B, 2=C, 3=D. `id` должен быть уникальным внутри предмета. При `visual=true` укажите существующее изображение и его размеры в пикселях. Для обычного текста изображение не требуется.

В `tools/import_bank.py` находится воспроизводимый импорт именно для макета предоставленных PDF. Требует `pdfplumber`, `pypdf`, `pypdfium2`, `Pillow`. Вопрос принимается только при наличии четырёх меток A–D и соответствующего ключа. Отчёты — `tools/import-report.json` и `tools/import-report-cluster{3,4,5}.json`. Импорт повторно записывает соответствующие банки и фрагменты; ручные добавления сначала сохраните отдельно.

```powershell
python tools/import_bank.py "C:\Users\ASUS\Downloads\ММТ 2кластер" --cluster 2 --limit 200
python tools/import_bank.py "C:\Users\ASUS\Downloads\ММТ 3 кластер" --cluster 3 --limit 0
python tools/import_bank.py "C:\Users\ASUS\Downloads\ММТ 4кластер" --cluster 4 --limit 0
python tools/import_bank.py "C:\Users\ASUS\Downloads\ММТ 5кластер" --cluster 5 --limit 0
python tools/validate_bank.py
python -m unittest discover -s tools -p "test_*.py" -v
```

Для нового PDF сначала проверьте разметку: номера могут повторяться между разделами, вопросы могут ссылаться на общий текст. Не применяйте импортёр к другому макету без адаптации и визуальной проверки. Добавление новых заданий в базу делается через исходники; загрузка PDF самим пользователем в приложении пока не предусмотрена.

`tools/pdf_clean.py` удаляет только служебные блоки, явно помеченные `/Artifact /Subtype /Watermark`, сохраняя остальные операции PDF. В версии 0.1 водяной знак отфильтровывался только при извлечении текста, поэтому оставался в растровых фрагментах математики. В версии 0.2 все фрагменты пересозданы после удаления этих блоков. Обычные повёрнутые подписи, серые рисунки, формулы и линии не стираются по цвету или углу.

## Структура

- `MainActivity.kt` — Compose-экраны и тема.
- `QuestionBank.kt` — чтение и проверка локальных данных.
- `QuizSession.kt` — независимая логика попытки.
- `PrepViewModel.kt` — состояние экранов и восстановление попытки.
- `QuizSessionTest.kt` — проверки выборки, фиксации ответа, подсчёта и восстановления.

Сборка использует AGP 8.13.2, Gradle 8.13, Kotlin/Compose compiler 2.0.20 и Compose BOM 2024.09.00. Версии зафиксированы для воспроизводимой сборки; обновление до последних версий не является частью первой версии.

- `assembleDebug`: успешно.
- `testDebugUnitTest`: 11 тестов, 0 ошибок (логика попытки, каталог пяти кластеров, совместное использование банков).
- Python: 3 проверки удаления водяных знаков, 0 ошибок. Проверяется сохранность остальных PDF-операций, включая повёрнутые подписи и рисунки.
- `lintDebug`: 0 ошибок; 7 предупреждений об обновлениях SDK/зависимостей и настройке backup, 1 рекомендация по состоянию Compose. Они не блокируют тестовую сборку.
- `validate_bank.py`: 3491 вопрос, ключи и 17455 фрагментов изображений; для литературы, истории, права и трёх предметов кластера 5 проверяется полнота разделов с одним ответом.
- `tools/smoke_clusters13.py`: восемь входов в предметы кластеров 1/3 с проверкой ответов, восстановление физики и литературы после завершения процесса, полный тест по литературе из 25 уникальных вопросов с результатом 12/25 (48%) и возврат в кластер 3.

Скриншоты находятся в `preview/`, протокол новой проверки — `preview/smoke-clusters13-results.json`; остальные `smoke-*.json` — протоколы предыдущих версий. Драйвер запускается на открытом главном экране приложения и требует доступного `adb` и эмулятора (по умолчанию `emulator-5554`). Проверка завершает тестовые попытки внутри приложения. Сценарии предыдущих версий сохранены отдельно.

Передаваемый APK — debug-сборка для локальной проверки. Сервер, учётные записи, постоянная история результатов, оплата и публикация в магазине в эту версию не входят.
